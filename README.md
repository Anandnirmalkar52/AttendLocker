# AttendLocker
A modern, DigiLocker-inspired B.Tech attendance manager with smart absence simulation, target tracking, and Supabase RLS security. AttendLocker is a modern, mobile-friendly personal attendance tracker built for B.Tech students. Inspired by DigiLocker's clean UI, it features real-time subject tracking, predictive absence impact calculations, target recovery analytics, and secure multi-user data storage via Supabase. Design: DigiLocker-inspired blue-and-white theme with responsive mobile bottom navigation. Smart Simulator: Instantly previews how missing upcoming classes impacts overall attendance percentage points. Target Calculator: Calculates maximum allowable absences or required consecutive classes to maintain 75% target. Tech Stack: React, TypeScript, Tailwind CSS, Vite, Supabase Auth & PostgreSQL (RLS).
